# dsh-opc 桌宠（经理）动画 + 电视通知 规格

桌宠是"经理"：本体不表达具体会话，只表达"在不在工作"；**需要你交互的事（权限/错误/长运行/答完）走老式电视通知**。

## 本体角色

chibi 女仆鲸尾（`assets/raw/桌宠/dreamina_*.jpg`）：
红蓝异色瞳、黑长发蓝挑染、动物耳+飞翼、鲸鱼/海豚尾鳍、黑白女仆装（蝴蝶结、鲸徽章、白头饰）。

## 本体动画 —— 只有两个（支持随机轮换）

| key          | 触发                                     | 动画动作                                | 循环 |
| ------------ | ---------------------------------------- | --------------------------------------- | ---- |
| `pet-idle`   | **无法连接到 DSH**，或**无任何会话事件** | 趴着/坐下待机，缓慢呼吸、眨眼、尾巴轻摆 | loop |
| `pet-submit` | 有会话在提交/运行（有事件）              | 敲击/忙碌、看屏、偶尔擦汗               | loop |

- 每个 key 做 **多个变体**，桌宠**随机轮换**：`pet-idle-0.webm`、`pet-idle-1.webm`、…（`pet-submit-0.webm`、`pet-submit-1.webm`…）。桌宠每次显示从该 key 的变体里随机选一个（同办公室角色/右下角浮窗的 `animationUrl` 逻辑一致）。
- 后台基于"当前快照是否产生事件/是否已连接"在这两个状态间切换：有连接且最近有会话事件 → `submit`；否则 → `idle`。

## 通用 WebM 规格

- VP9 **WebM**、**透明**（`yuva420p`；无 alpha 用 `yuv420p`）、`muted`、无缝循环（首尾姿势一致）。
- 画幅 640×640（或 480×480），主体**居中贴地**、占 70–85%、留边距；主体不动、细节动，勿整帧闪。
- 时长 2–8 秒；变体之间动作略不同（比如 submit 敲击节奏、idle 头朝向不同）。

## 电视通知（交互报告的主体）

桌宠本体旁边弹出一个小窗，渲染成**老式 CRT 电视**：弧面屏、边框、扫描线/噪点，屏幕**按通知类型用不同颜色**，屏幕中央是通知文案，顶部小字"DSH 通知"。

### 屏幕颜色按类型

| 类型       | 触发                              | 屏幕色     | 文案                    |
| ---------- | --------------------------------- | ---------- | ----------------------- |
| **权限**   | 会话 `await`（请求授权）          | **琥珀黄** | 「×× 请求授权：<tool>」 |
| **错误**   | 会话 `error`（连接失败/工具出错） | **红**     | 「×× 出错：<summary>」  |
| **长运行** | 会话活动工具超过阈值              | **蓝**     | 「×× 已运行 N 分钟」    |
| **答完**   | 会话 `running→idle`（上一轮完成） | **绿**     | 「×× 上一轮已完成」     |

### 长运行阈值：指数策略

该会话**连续运行**时按 **5 → 10 → 20 → 40 → 80…（每档 ×2）分钟** 提醒，每会话每档去重（跨重启不重复，沿用通知 ledger）；会话回到 idle/error 或切换则重置。

### 通知行为

- 一条电视通知**最多短暂停留**，多条排队按优先级（权限>错误>长运行>答完）依次显示；屏幕色随类型。
- **点击电视通知**：打开 DSH 网页，跳到**对应会话的对话**。若当前网页处于**根路径（`/`，且不在 `/office`）**，就直接落在该会话对话；若在 `/office` 等专属页则按后续约定处理。
- 可配声音、免打扰（设置项后续）。

## 窗口与交互

- 透明、无边框、置顶、跳过任务栏；可拖拽，按显示器记忆并 clamp 位置。
- 系统托盘：显示/隐藏、重连、打开 DSH、设置、退出（关窗=隐藏，退出=清存在信号）。
- 底部可展开"会话列表"：会话名 + 状态灯 + 是否有待交互通知。
- 后端原生通知沿用现有 ledger 逻辑（权限/错误/长运行去重、合并同时段为摘要）。

## 素材落地

你做好的本体动画放 `assets/characters/pet-manager/`（如 `pet-idle-0.webm`、`pet-submit-1.webm`），在 `assets/manifest.json` 登记该角色；本地可 `pnpm assets:dummy` 生成占位跑通。电视通知不需要动画素材——由 CSS/前端绘制，屏幕色/文案由桌宠逻辑决定。
